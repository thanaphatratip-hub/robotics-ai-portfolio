# Thanaphatra Tipchanyavatra: Robotics & AI projects

Third-year Robotics & AI Engineering student at KMITL (International Program, Bangkok).
I take vision and sensor models from raw data to running hardware, and I build web apps for real businesses.

| Project | What it is | Stack | Team |
|---|---|---|---|
| [PPE Detection System](ppe-safety-detection) | Real-time helmet / vest / goggles check on a Jetson Nano, with PASS/WARNING and an alarm | YOLO11, Roboflow, OpenCV, Jetson Nano | Lead, team of 6 |
| [TinyML Machine-Speed Classifier](tinyml-machine-speed-classifier) | Classifies motor speed from vibration on a microcontroller (~1 ms inference) | Arduino Nano 33 BLE, Edge Impulse | Team of 2 |
| [SmartPharma Pill Counter](smartpharma-pill-counter) | Counts and sorts pills from a webcam with classical computer vision | Python, OpenCV, 3D printing | Team of 2 |
| [VerveCar Back Office](vervecar-back-office) | Live back-office app for a car importer: stock, sales, finance calculator, documents | React, TypeScript, Supabase | Team of 2 (built most of it) |
| [Metal-Roof Sales Dashboard](metal-roof-sales-dashboard) | Browser-only sales dashboard for a real company, with role-based views and a forecast | HTML, JavaScript | Own version (class project) |
| [Leaf-Collecting Raft](leaf-collecting-raft) | Autonomous raft that collects floating leaves; I printed, sealed and assembled the hardware | 3D printing, epoxy, waterproofing | Hardware team, 3 of 10 |
| [MC.RAI7 Web Store](mc-rai7-web-store) | Minecraft-server web store with accounts, shop and leaderboard | Next.js, FastAPI, PostgreSQL | Team of 2 |

Each folder has its own README with what I personally did.
